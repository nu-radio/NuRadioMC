11 """ 

12 Calculates the trigger for a phased array with primary beam locations 

13 using a power integrated envelope. This module allows access to lower level options

46 """ 

47 simulates phased array trigger for each event 

48 

49 Several channels are phased by delaying their signals by an amount given 

50 by a pointing angle. Several pointing angles are possible in order to cover 

51 the sky. The array triggered_channels controls the channels that are phased, 

52 according to the angles phasing_angles. 

53

57 Description of the current event 

58 station: Station object 

59 Description of the current station 

60 det: Detector object 

61 Description of the current detector 

62 Vrms: float 

63 RMS of the noise on a channel, used to automatically create the digitizer 

64 reference voltage. If set to None, tries to use reference voltage as defined 

65 int the detector description file. 

66 threshold: float 

67 threshold above (or below) a trigger is issued, absolute amplitude 

68 triggered_channels: array of ints 

69 channels ids of the channels that form the primary phasing array 

70 if None, all channels are taken 

71 trigger_name: string 

72 name for the trigger 

73 phasing_angles: array of float 

74 pointing angles for the primary beam 

75 set_not_triggered: bool (default False) 

76 if True not trigger simulation will be performed and this trigger will be set to not_triggered 

77 ref_index: float (default 1.75) 

78 refractive index for beam forming 

79 trigger_adc: bool, (default True) 

80 If True, uses the ADC settings from the trigger. It must be specified in the 

81 detector file. See analogToDigitalConverter module for information 

82 clock_offset: float (default 0) 

83 Overall clock offset, for adc clock jitter reasons 

84 adc_output: string (default 'voltage') 

85 

86 - 'voltage' to store the ADC output as discretised voltage trace 

87 - 'counts' to store the ADC output in ADC counts 

88 

89 trigger_filter: array floats (default None) 

90 Freq. domain of the response to be applied to post-ADC traces 

91 Must be length for "MC freq" 

92 upsampling_factor: integer (default 1) 

93 Upsampling factor. The trace will be a upsampled to a 

94 sampling frequency int_factor times higher than the original one 

95 after conversion to digital 

96 window: int (default 32) 

97 Power integration window for averaging 

98 Units of ADC time ticks 

99 averaging_divisor: int (default 32) 

100 Power integral divisor for averaging (division by 2^n much easier in firmware) 

101 Units of ADC time ticks 

102 step: int (default 16) 

103 Time step in power integral. If equal to window, there is no time overlap 

104 in between neighboring integration windows. 

105 Units of ADC time ticks 

106 apply_digitization: bool (default True) 

107 Perform the quantization of the ADC. If set to true, should also set options 

108 `trigger_adc`, `adc_output`, `clock_offset` 

109 upsampling_method: str (default 'fft') 

110 Choose between FFT, FIR, or Linear Interpolaion based upsampling methods 

111 coeff_gain: int (default 1) 

112 If using the FIR upsampling, this will convert the floating point output of the 

113 scipy filter to a fixed point value by multiplying by this factor and rounding to an 

114 int. 

115 filter_taps: int (default 45) 

116 If using FIR upsampling these are the number of filter coefficients 

117 saturation_bits: int (default 8) 

118 If using counts, determines how large the coherently summed waveforms will saturate 

119 return_n_triggers: bool (default False) 

120 To better estimate simulated thresholds one should count the total triggers

122 

123 Returns

126 True if the triggering condition is met
